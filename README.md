# Personal Portfolio

A single-page, formal yet colorful portfolio with subtle animations, built with plain HTML, CSS, and JavaScript.

## How to run

You can simply open `index.html` in your browser:

1. Open the folder on your machine: `c:\Users\LRS\Desktop\portfolio`.
2. Double-click `index.html` or right-click and choose “Open with” → your browser.

For a slightly better experience (no file URL restrictions), you can use a simple local server, for example with Python:

```bash
cd "c:\Users\LRS\Desktop\portfolio"
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Customization

Open `index.html` and replace all placeholders such as:

- `Your Name`
- `Your Role / Title`
- `Your City, Country`
- Dummy project titles and descriptions
- Contact details (`your.email@example.com`, links, etc.)

You can also adjust colors in `styles.css` at the top in the `:root` section.
